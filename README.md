# Meta Ads Intelligence Dashboard

## Overview
An interactive Power BI dashboard designed to analyze Meta advertising campaign performance, platform activity, audience demographics, and engagement patterns.

## Dashboard Features
- KPI cards for impressions, clicks, CTR, engagements, purchases, and campaign budget
- Campaign performance trends
- Top 10 campaign ranking
- Facebook and Instagram comparison
- Geographic campaign performance map
- Purchases by gender
- Hourly engagement analysis
- Interactive date, platform, ad type, and campaign filters
- Dynamic metric selector for impressions, clicks, engagements, and purchases

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Structure
- `Meta_Ads_Intelligence.pbix` — Power BI report
- `screenshots/` — Dashboard preview images
- `data/` — Dataset documentation

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Refresh the data sources if required.
4. Explore the report using the interactive slicers and metric selector.

## Data Disclaimer
Document the dataset source, license, and whether the data is simulated or real. Do not interpret budget as actual advertising spend unless the dataset supports that distinction.
